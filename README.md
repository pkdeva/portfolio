# Portfolio

## How to Run This Project

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:5173` (default Vite port).

   ```bash
   npx vite --host
   ```
   The app will get exposed over all network interfaces.

3. **Build for production**
   ```bash
   npm run build
   ```

4. **Preview the production build**
   ```bash
   npm run preview
   ```

5. **Lint the code**
   ```bash
   npm run lint
   ```

6. **Type check**
   ```bash
   npm run typecheck
   ```
